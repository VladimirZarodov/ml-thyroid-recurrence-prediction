Проект посвящён анализу клинических данных пациентов с раком щитовидной железы и построению моделей машинного обучения для предсказания рецидива заболевания.

## О проекте

Цель — на основе клинических признаков (возраст, пол, стадия, TNM, гистология и т.д.) предсказать, возникнет ли рецидив у пациента. В работе:

- проводится разведочный анализ данных (наполненность атрибутов, пропуски, корреляции, влияние признаков на целевую переменную);
- сравниваются три модели — **XGBoost**, **Linear SVM**, **Random Forest**;
- для каждой модели выполняется подбор гиперпараметров (`GridSearchCV`);
- проверяется, как изменение структуры набора данных (состав и формат признаков) влияет на качество моделей;
- по итогам всех экспериментов выбирается наиболее эффективная модель.

Ноутбук [`Pred_thyroid`](./Pred_thyroid.ipynb) содержит полный пайплайн: загрузку данных, EDA, предобработку, обучение и подбор параметров моделей, эксперимент с альтернативной структурой данных и итоговое сравнение результатов.

## Данные

Используется файл [`filtered_thyroid_data`](./filtered_thyroid_data.csv), содержащий следующие признаки:

| Признак | Описание |
|---------|----------|
| Age | Возраст пациента |
| Gender | Пол (F/M) |
| Hx Radiothreapy | Радиотерапия в анамнезе (No/Yes) |
| Adenopathy | Аденопатия (No/Right/Extensive/Left/Bilateral/Posterior) |
| Pathology | Гистологический тип (Micropapillary, Papillary, Follicular, Hurthel cell) |
| Focality | Фокальность (Uni-Focal / Multi-Focal) |
| Risk | Группа риска (Low / Intermediate / High) |
| T | Категория T (T1a, T1b, T2, T3a, T3b, T4a, T4b) |
| N | Категория N (N0, N1a, N1b) |
| M | Категория M (M0, M1) |
| Stage | Стадия (I, II, III, IVA, IVB) |
| Response | Ответ на лечение (Excellent, Indeterminate, Biochemical Incomplete, Structural Incomplete) |
| **Recurred** | **Целевая переменная:** No / Yes |

## Методология

### 1. Разведочный анализ данных (EDA)

- Проверка размера датасета, типов данных и наполненности атрибутов (столбчатая диаграмма процента заполненности по каждому признаку).
- Поиск пропущенных значений (`isnull().sum()`) и полностью дублирующихся строк.
- Построение матрицы корреляции признаков (тепловая карта).
- Оценка влияния каждого признака на целевую переменную `Recurred` — корреляция с таргетом, отсортированная по силе влияния, и диаграмма-визуализация.

### 2. Предобработка данных (исходная структура)

- Категориальные признаки закодированы с помощью `LabelEncoder`.
- Целевая переменная `Recurred` преобразована в бинарную: `No → 0`, `Yes → 1`.
- Данные разделены на обучающую и тестовую выборки в пропорции 80/20 (`random_state=42`).
- Признаки нормализованы с помощью `StandardScaler`.


### 3. Обучение моделей и подбор гиперпараметров

Для каждой модели сначала обучается базовая версия с параметрами «по умолчанию», а затем выполняется подбор гиперпараметров по сетке (`GridSearchCV`, 5-fold cross-validation, метрика `accuracy`):

| Модель | Базовые параметры | Параметры для перебора |
|--------|--------------------|--------------------------|
| **XGBoost** (`XGBClassifier`) | `eval_metric='logloss'` | `n_estimators`, `max_depth`, `learning_rate`, `subsample` |
| **Linear SVM** (`LinearSVC`) | `max_iter=20000` | `C`, `loss` |
| **Random Forest** (`RandomForestClassifier`) | `n_estimators=100` | `n_estimators`, `max_depth`, `min_samples_split`, `min_samples_leaf` |

По каждой модели в ноутбуке выводятся лучшие найденные параметры и точность на кросс-валидации, после чего лучшая версия модели оценивается на тестовой выборке (accuracy, precision, recall, f1-score).

### 4. Изменение структуры набора данных

Чтобы оценить, как состав и формат признаков влияют на качество моделей, строится альтернативная версия датасета:

- **`Age` → `Age_Group`** — непрерывный возраст заменяется на возрастную группу (`<=30`, `31–45`, `46–60`, `60+`).
- **Удаляются `T`, `N`, `M`** — эти признаки детализируют стадию заболевания, информация о которой уже во многом содержится в агрегированном признаке `Stage` (что видно по матрице корреляции); это снижает мультиколлинеарность и размерность признакового пространства.
- **One-Hot Encoding** применяется к номинальным признакам без естественного порядка (`Gender`, `Hx Radiothreapy`, `Adenopathy`, `Pathology`, `Focality`, `Age_Group`) вместо `LabelEncoder`, чтобы не задавать моделям ложный порядок между категориями.
- Для признаков с естественным порядком (`Risk`, `Response`, `Stage`) сохраняется порядковое (ordinal) кодирование.

На новой структуре данных все три модели заново обучаются с подбором гиперпараметров (`GridSearchCV`) по тем же сеткам параметров.

### 5. Оценка влияния изменения структуры

Точность моделей на исходной и на изменённой структуре данных сравнивается визуально (столбчатая диаграмма) и численно (разница accuracy по каждой модели), что позволяет судить, помогло ли изменение состава признаков или ухудшило результат.

### 6. Выбор наиболее эффективной модели

Все полученные варианты — базовые параметры / подобранные параметры, исходная структура / изменённая структура — сводятся в единую таблицу результатов, отсортированную по точности на тестовой выборке. Модель и конфигурация с наивысшей точностью выбираются как итоговое решение.
